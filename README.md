# Forensic Odontology — Dental Age Assessment Lecture System

This version is designed as a **lecture and practical-teaching tool**, with dental age assessment as the main focus.

## Main teaching pathway
1. FDI Quick Guide — rapid recognition of FDI numbers used in practicals.
2. Tooth Eruption Timeline — visual age-related eruption.
3. Learn — structured dental age assessment teaching content.
4. 3D Tooth / Label — morphology and practical orientation.
5. Gustafson — adult age estimation and APSRTC.
6. Individual Gustafson parameters — attrition, periodontosis, secondary dentin, root resorption, transparency and cementum apposition.
7. Viva / Exam — assessment and revision.
8. 3D Clinic — lecture navigation hub.

## Scope intentionally kept focused
- Dental age assessment is the primary subject.
- FDI numbering is included only as a practical identification aid.
- Bite-mark analysis is not part of the teaching pathway.
- Detailed comparison/classification of Palmer, Universal, Haderup and other charting systems is not part of the module.
- No AI tutor is included in this version.

## 3D models
The large 3D model assets are intentionally kept outside this lightweight package. Place the existing `models/` directory beside these HTML files when deploying the complete version.

## Source/teaching basis
The lecture content should continue to be checked against the department's chosen textbook/reference and local curriculum. The uploaded source used for the present focus includes tooth development/eruption and Gustafson's six physiological changes (APSRTC).
