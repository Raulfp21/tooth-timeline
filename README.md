# Forensic Odontology Teaching Modules

Interactive teaching tools for MBBS forensic medicine students.

Topics covered:
- Tooth eruption timeline (birth to 25 years)
- Age estimation from teeth (eruption chart method + Gustafson's method)
- FDI notation
- Primary vs permanent morphology (3D)
- Superadded vs successional teeth

Data source: Reddy's Forensic Medicine, 36th ed. Tables 4.7, 4.8, 4.9.

3D models: University of Dundee School of Dentistry (CC-BY).

Live: https://raulfp21.github.io/tooth-timeline/
